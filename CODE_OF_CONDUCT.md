# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En corto: tratá a todos con respeto, discutí ideas y no personas, y asumí buena fe. Las discusiones sobre
"qué nube es mejor" son bienvenidas solo si traen hechos y fuentes.

Para reportar un problema de conducta, escribí a los mantenedores por un canal privado (mensaje directo en
GitHub o LinkedIn al mantenedor que figura en `.github/CODEOWNERS`). Los reportes se tratan con confidencialidad.
